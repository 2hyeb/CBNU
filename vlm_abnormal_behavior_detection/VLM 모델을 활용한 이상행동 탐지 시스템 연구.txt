llama3.1 70B의 경우, GGUF 포맷으로 양자화된 모델을 Ollama를 통해 서빙하고 있으며, Ollama 내부 엔진에서 멀티 GPU 분산을 지원함 그래서 70B급 모델도 여러 장의 GPU VRAM에 나누어 올려서 추론이 가능
반면 Qwen2.5-VL-72B는 대규모 LLM에 더해 비전 인코더가 결합된 멀티모달 구조를 갖고 있어, 순수 LLM 대비 파라미터 규모와 메모리 요구량이 더 큼
현재 시점 기준으로는 이 모델을 안정적으로 변환하고 서빙하는 공개 파이프라인이 없고, 멀티모달 구조 탓에 기존 GGUF도 활용하기 어려움
Qwen2.5-VL-72B는 Hugging Face Transformers + PyTorch 조합으로 직접 로드해서 사용하는 방식이 최선의 선택이고 LLM처럼 멀티 GPU tensor parallel로 운용하기가 어려움
